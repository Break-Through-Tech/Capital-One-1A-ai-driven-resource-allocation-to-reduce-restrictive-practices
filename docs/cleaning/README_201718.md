## Start here (plain English)

- **What is this?** The cleaned 2017-18 school data for our project. It is one table:
  each row is one U.S. public school (97,632 schools), and each column is one fact
  about that school (50 columns, the same 50 columns every school year uses).

  twice at this school". Flagged values were NOT changed.
- **How was it made?** The notebook `notebooks/clean_201718.ipynb` reads the
  government's raw files and builds the table step by step, with an explanation before

## How to read the CSVs correctly

```python
import pandas as pd

ids = {"combokey": str, "leaid": str, "schid": str}
schools = pd.read_csv("schools_201718.csv", dtype=ids, float_precision="round_trip")
```

- Always read the three ID columns as text. Otherwise IDs like `0100002` lose their
  leading zero.
- `float_precision="round_trip"` reads every number exactly as written. Without it,
  pandas may change the last digit of some decimals (a tiny difference, less than 1e-12
  of the value).
- Opening a CSV in Excel just to look is fine, but never save it from Excel: Excel
  strips the leading zeros from IDs.

## Known caveats (details in `qa_201718.md`)

- Total enrollment appears to include preschool children, while the seclusion counts
  appear to cover K-12 and ungraded students only. Rates may be slightly low for schools
  with preschool (26,365 of the analysis-ready schools).
- New York City (1,603 schools) reports zero seclusion at every school. Kept as reported.
- Philadelphia (217 schools) and Stafford County, VA (32 schools) did not report
  seclusion for some student groups, so their totals are blank.
- Staffing values that look like entry errors (for example 102,579 security guards at one
  school) are flagged with `flag_fte_outlier`, not changed. The review covered the
  largest values only, so it is not exhaustive.
- Very small schools can have very large rates (for example 3,250 incidents per 100
  students at a school with 2 students). Use `flag_small_enrollment`.

## 2017-18 notes on specific columns

- `enr_nonbinary` and `sch_virt_ind` are always blank: 2017-18 did not collect them.
- The four `flag_partial_*` columns, `flag_missing_module` and `flag_missing_lea` are
  always False: every school matched every raw table and its district.
- `jj` = "Yes" means a long-term secure juvenile justice facility (stays over 90 days);
  602 schools.
- `fte_guards` is blank at all 602 juvenile justice schools (reported as "not
  applicable").
- `fte_teachers` includes special-education and preschool teachers. `fte_leo` counts
  sworn law enforcement officers (can include school resource officers); `fte_guards`
  counts security guards who are not sworn officers (2017-18 Master List of CRDC
  Definitions).
- Seclusion, as defined for 2017-18: confining a student alone in a room or area that the
  student is physically prevented from leaving. Timeouts are not seclusion (2017-18
  Master List of CRDC Definitions).
- The first 2 characters of `leaid` are the state FIPS code (for example `06` =
  California).
- Counts are written as decimals (for example `133.0`), as the playbook's "nullable
  float" type requires.
- `enr_el` comes from the raw "LEP" (limited English proficient) columns.
- `pct_idea` is blank at 233 schools and `pct_el` at 21: at 222 and 10 of them the
  subgroup count is larger than the total; at the other 11 the enrollment total is
  blank.
- 510 rows have official district IDs that contain letters: `06CC###` (California,
  mostly charter schools) and `##SOP##` (state-run programs). They are valid; keep them
  as text.
- A few districts report `lea_schools` = 0 although they have schools; kept as reported.
- One school name is garbled in the government's own file (James J Ferris High School,
  340783002774). It was kept exactly as in the source.

## Missing-data codes in the 2017-18 raw files

The raw files store missing values as negative codes. All of them became blank.
Meanings from the 2017-18 Public Data File Manual (section 5.1.1, Table 2, p.12):

| Raw code | Meaning |
|---|---|
| -3 | Skip logic failure |
| -5 | Action plan (the district did not report and filed a plan to fix it) |
| -6 | Force certified (the district did not finish reporting) |
| -8 | EDFacts missing data |
| -9 | Not applicable / skipped (for example, seclusion at preschool-only schools) |
| -11 | Suppressed (hidden by the government for data-quality reasons) |

The team's earlier data audit and dictionary give wrong meanings for -5 and -9; the
meanings above come from the official manual.
