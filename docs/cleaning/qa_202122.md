## Unresolved issues and notes

- 9 mapping rows are marked unresolved. See mapping_202122.csv.
- TOT_ENR_M, TOT_ENR_F and TOT_ENR_X are calculated totals. The appendix does not say whether they include preschool students, so rates that use them need that check. The manual says totals were built by treating reserve codes as zero, so a total can be a partial sum.
- JJ is not listed in Appendix Sheet B. JJ was kept as the main source and compared with SCH_JUST_IND.
- Negative values that are not 2021-22 reserve codes: 0.
- flag_analysis_ready uses the data rules only: a valid seclusion total and positive enrollment. The enrollment coverage question above is still open.
- Public-use student counts were perturbed by one case (manual 5.2.1), so small counts are slightly noisy.
- The playbook names grade columns SCH_GRADE_G1 to G12. The real headers are zero-padded (SCH_GRADE_G01 to SCH_GRADE_G12), and the script uses those.
